# ブラウザ・バレーボール 3 vs 3

3人 vs 3人でラリーするブラウザ用カジュアルバレーボールゲーム。
自陣後方からコートを見る疑似3D視点で、先に **5点** 取った側の勝ちです。

## ▶ 遊ぶ

**https://inoueharuto42.github.io/browser-volleyball/**

ブラウザで開くだけで遊べます(PC・キーボード操作専用)。

## ルール

- 緑の▽が付いたキャラを操作します(青は味方AI、赤は相手CPU)
- ボールは **必ず3タッチで** 相手コートに返します
  - 1・2回目のタッチ: 自陣前方への **トス**(つなぎ)
  - 3回目のタッチ: **ジャンプ中にしか打てないスパイク** で相手コートへ
- **同じキャラは連続でボールに触れません**(仲間とつなぐ必要があります)
- ボールが自陣の地面に落ちると相手に1点。4回目のタッチもオーバータッチで相手に1点
- サーブは得点した側から。`Enter` を押すとサーブが始まります
- ボールの予測落下地点が黄色いリングで表示されます
- 合計得点が2点入るごとにCPUが最大3段階強くなります(移動・反応・球速)

## 操作

| キー | 動作 |
|---|---|
| `← → ↑ ↓` | コート上を前後左右に移動 |
| `Space` | ジャンプ(スパイクに必須) |
| `S` | ボールを打つ(トス/レシーブ/スパイク) |
| `Enter` | サーブ開始 |
| `R` | 結果画面からタイトルに戻る |

## ローカルで動かす

```
git clone https://github.com/InoueHaruto42/browser-volleyball.git
cd browser-volleyball
open index.html   # またはブラウザで index.html を直接開く
```

ビルド不要・外部ライブラリなし(素の HTML + CSS + JavaScript / Canvas 2D)。
